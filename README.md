# C# To-Do アプリケーション

シンプルで使いやすいコンソールベースの To-Do リスト管理アプリケーションです。

## 機能

- ✅ To-Do アイテムの追加
- 📋 To-Do リストの一覧表示
- 🔍 To-Do の詳細表示
- ✓ To-Do の完了/未完了の切り替え
- 🗑️ To-Do の削除
- 💾 JSON ファイルへのデータ永続化

## 必要な環境

- .NET SDK 10.0 以降

## ビルド方法

```bash
cd src/TodoApp
dotnet build
```

## 実行方法

```bash
cd src/TodoApp
dotnet run
```

## 使い方

アプリケーションを起動すると、メニューが表示されます：

```
═══════════════════════════════════
   未完了タスク: 0件
═══════════════════════════════════

メニュー:
  1. To-Do を追加
  2. To-Do 一覧を表示
  3. To-Do の詳細を表示
  4. To-Do を完了にする
  5. To-Do を未完了に戻す
  6. To-Do を削除
  0. 終了

選択してください: 
```

### To-Do の追加

1. メニューから `1` を選択
2. タイトルを入力（必須）
3. 説明を入力（省略可能）

### To-Do の一覧表示

メニューから `2` を選択すると、全ての To-Do が表示されます。
未完了のアイテムが上に表示され、完了したアイテムにはチェックマーク（✓）が付きます。

```
[ ] 1. 買い物に行く
[ ] 2. レポートを書く
[✓] 3. メールを返信する
```

### To-Do の完了

1. メニューから `4` を選択
2. 完了したい To-Do の ID を入力

### To-Do の削除

1. メニューから `6` を選択
2. 削除したい To-Do の ID を入力
3. 確認メッセージで `y` を入力

## データの保存

To-Do データは `todos.json` ファイルに自動的に保存されます。
アプリケーションを再起動しても、データは保持されます。

```

```
