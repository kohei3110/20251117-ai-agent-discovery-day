# C# ToDoアプリ

シンプルで使いやすいコンソールベースのToDoアプリケーションです。

## 機能

- ✅ ToDoアイテムの追加
- ✅ ToDoリストの表示（すべて/未完了のみ）
- ✅ ToDoアイテムを完了にする
- ✅ ToDoアイテムの削除
- ✅ 統計情報の表示
- ✅ JSONファイルへのデータ永続化

## 必要な環境

- .NET 10.0 SDK以上

## ビルド方法

```bash
dotnet build
```

## 実行方法

```bash
dotnet run
```

## 使い方

アプリを起動すると、以下のメニューが表示されます：

```
=== C# ToDoアプリ ===

コマンドを選択してください:
1. ToDoアイテムを追加
2. ToDoリストを表示
3. 未完了のToDoを表示
4. ToDoを完了にする
5. ToDoを削除
6. 統計情報を表示
7. 終了
```

### 1. ToDoアイテムを追加

新しいToDoアイテムを追加します。タイトル（必須）と説明（任意）を入力できます。

### 2. ToDoリストを表示

すべてのToDoアイテム（完了済みを含む）を表示します。

### 3. 未完了のToDoを表示

未完了のToDoアイテムのみを表示します。

### 4. ToDoを完了にする

指定したIDのToDoアイテムを完了状態にします。

### 5. ToDoを削除

指定したIDのToDoアイテムを削除します。

### 6. 統計情報を表示

合計、完了、未完了のアイテム数を表示します。

### 7. 終了

アプリケーションを終了します。

## データの保存

ToDoアイテムは `todos.json` ファイルに自動的に保存されます。アプリを再起動しても、データは保持されます。

## プロジェクト構成

- `Program.cs` - メインプログラムとユーザーインターフェース
- `TodoItem.cs` - ToDoアイテムのモデルクラス
- `TodoManager.cs` - ToDoアイテムの管理とCRUD操作
- `todos.json` - データ保存ファイル（自動生成）
