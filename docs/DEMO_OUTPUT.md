# C# To-Do アプリケーション - デモ出力

## アプリケーション起動画面

```
═══════════════════════════════════
   C# To-Do アプリケーション
═══════════════════════════════════

═══════════════════════════════════
   未完了タスク: 0件
═══════════════════════════════════

メニュー:
  1. To-Do を追加
  2. To-Do 一覧を表示
  3. To-Do の詳細を表示
  4. To-Do を完了にする
  5. To-Do を未完了に戻す
  6. To-Do を削除
  0. 終了

選択してください:
```

## To-Do 追加の例

```
─── To-Do の追加 ───
タイトル: プロジェクトの企画書を作成
説明（省略可能）: 来週の会議で発表する内容

✓ To-Do を追加しました（ID: 1）
```

## To-Do 一覧表示

```
─── To-Do 一覧 ───
[ ] 1. プロジェクトの企画書を作成
[ ] 3. ジムに行く
[✓] 2. スーパーで買い物

合計: 3件（未完了: 2件）
```

## To-Do 詳細表示

```
─── To-Do の詳細 ───
To-Do ID: 2

ID: 2
タイトル: スーパーで買い物
説明: 牛乳、卵、パンを買う
状態: 完了
作成日時: 2025/11/17 07:40
  完了日時: 2025/11/17 07:42
```

## 機能まとめ

✅ **実装済み機能:**
- To-Do の追加（タイトルと説明）
- To-Do の一覧表示
- To-Do の詳細表示
- To-Do の完了/未完了切り替え
- To-Do の削除
- JSON ファイルによるデータ永続化
- 日本語 UI

📊 **技術スタック:**
- .NET 10.0
- C# コンソールアプリケーション
- System.Text.Json
